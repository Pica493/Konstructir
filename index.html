Покупка монет (Яндекс Игры)

⚠️ Важно. Это настоящие платные покупки через платформу Яндекс Игры (Yandex Games SDK). Чтобы они реально работали:
1. Опубликуйте игру в кабинете разработчика Яндекс Игр.
2. В разделе «Каталог покупок» создайте товар с ID, который вы укажете здесь в поле «ID товара» — ID должны совпадать буква в букву.
3. Реальную цену покупатель увидит ту, что вы укажете в кабинете Яндекса — поле «Цена» здесь используется только для отображения в списке, пока игра открыта не на платформе Яндекс Игр (например, при тестовом просмотре).
4. Покупки работают только при запуске игры внутри Яндекс Игр — при локальном открытии файла магазин покажет уведомление вместо реальной оплаты.

Реклама РСЯ (Рекламная сеть Яндекса)

⚠️ Block ID берутся из личного кабинета Яндекс.Директ (раздел «Монетизация сайта» / РСЯ) после того, как вы зарегистрируете там свою площадку. Реклама РСЯ работает только когда игра открыта по адресу настоящего сайта (http/https), а не как локальный файл — перед экспортом загрузите готовый HTML на хостинг и укажите его в кабинете Яндекса. Полноэкранный блок — необязателен, оставьте поле пустым, если он не нужен.

⚡ При использовании подгрузки уровней из JSON, картинки должны быть доступны по прямым ссылкам.
